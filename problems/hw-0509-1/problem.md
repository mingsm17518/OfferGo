### 商品购买查询

手机号为 8 位十进制数字，范围为 `00000000` 到 `99999999`。某商城商家使用手机号注册，每个用户的购买情况被记录到商品清单里。

我们需要实现程序，在读取 2 个清单以后，给出同时出现在 2 个清单里的用户个数。

#### 输入描述

第一行表示 A 商品的清单内用户条数 N（0 ≤ N ≤ 10^7），接下来 N 行数字，每一行表示一个手机号码。

紧接着一行表示 B 商品的清单内用户条数 M（0 ≤ M ≤ 10^7），接下来 M 行数字，每一行表示一个手机号码。

输入格式为数字，前导 0 会省略。由于可能多次购买，输入可能重复。

#### 输出描述

输出一行一个数字，表示同时在两个商品清单中的用户个数。同一个用户仅统计一次。

#### 样例 1

**输入:**

```
3
0
3
5
4
1
4
5
99999999
```

**输出:**

```
1
```

#### 样例 2

**输入:**

```
2
0
3
4
0
20000004
3
99999999
```

**输出:**

```
2
```
