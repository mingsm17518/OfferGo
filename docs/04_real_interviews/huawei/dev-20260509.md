## 第二题：设备运行监控

### 题目描述

有 $n$ 台医疗设备，编号为1到 $n$，每台设备有一个当前的运行状态值。为了监控设备运行是否稳定，医院需要找出连续的设备序列，使得这些设备的运行状态值的差值都不超过某个阈值。

现在给定 $n$ 台设备的运行状态值和一个阈值 $d$，求最长的连续设备序列，使得序列中任意两台设备的运行状态值之差的绝对值不超过 $d$。如果有多解，输出起始编号最小的序列。

**输入描述**：

第一行：两个整数 $n, d$（$1 \le n \le 100000, 0 \le d \le 10000$），分别表示设备数量和允许的最大状态差值。

第二行：$n$ 个整数，表示 $n$ 台设备的运行状态值 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10000$）。

**输出描述**：

输出两个整数 $L, R$，表示最长连续设备序列的起始和结束编号（第一台设备编号为1）。

如果有多个长度相同的序列，输出起始编号最小的序列。

如果只有1台设备，或不存在满足条件的序列，则输出 `1 1`。

### 样例

**样例 1**

输入：

```
9 3
1 4 2 5 7 4 3 8 1
```

输出：

```
1 3
```

满足条件的最长序列为 [1,4,2]（起始编号1）、[4,2,5]（起始编号2）、[5,7,4]（起始编号4），起始编号1最小，因此答案为 `1 3`。

**样例 2**

输入：

```
12 5
5 7 9 6 8 10 12 15 13 14 16 18
```

输出：

```
1 6
```

**样例 3**

输入：

```
8 5
5 7 3 8 6 4 9 2
```

输出：

```
1 6
```

### 思路分析

**第一步：问题建模**

题目要求最长连续子数组，使得其中任意两个元素的差的绝对值不超过 $d$。任意两个元素的差值上界等价于该子数组的 **最大值减最小值不超过 $d$**，即 $\max - \min \le d$。

这是一个经典的"滑动窗口内维护最值"问题。

**第二步：滑动窗口 + 单调队列**

维护一个窗口 $[left, right]$，用两个单调队列分别跟踪窗口内的最大值和最小值：

- **单调递减队列** `max_dq`：队首始终是当前窗口的最大值
- **单调递增队列** `min_dq`：队首始终是当前窗口的最小值

每次右端 `right` 扩展时，先将新元素插入两个队列（维护单调性），然后检查 `max_dq[0] - min_dq[0] > d` 是否成立。若成立，则不断右移 `left` 收缩窗口，直到条件满足。

**第三步：记录最优解**

窗口收缩完毕后，当前窗口长度 `right - left + 1` 就是以 `right` 结尾的最长合法子数组。维护全局最大长度和对应的起始位置即可。由于我们是从左往右遍历，同等长度下自然保留最早（最小）的起始位置。

以样例 1 `[1, 4, 2, 5, 7, 4, 3, 8, 1]`，$d=3$ 为例：

| right | 窗口 | max | min | max-min | 合法？ | 最长 |
|-------|------|-----|-----|---------|--------|------|
| 0 | [1] | 1 | 1 | 0 | ✓ | 长度1 |
| 1 | [1,4] | 4 | 1 | 3 | ✓ | 长度2 |
| 2 | [1,4,2] | 4 | 1 | 3 | ✓ | 长度3 → 更新 best |
| 3 | [1,4,2,5] | 5 | 1 | 4 | ✗ → 收缩到 [4,2,5] | 5-2=3 ≤ 3 ✓ | 长度3（未更新，起始2 > 1） |
| ... | | | | | | |

最终最优解为起始1，长度3，输出 `1 3`。

### 题解代码

```python
from collections import deque

n, d = map(int, input().split())
a = list(map(int, input().split()))

max_dq = deque()  # 单调递减，队首为窗口最大值
min_dq = deque()  # 单调递增，队首为窗口最小值

best_l = 0
best_len = 1
left = 0

for right in range(n):
    # 维护单调递减队列（最大值）
    while max_dq and a[max_dq[-1]] <= a[right]:
        max_dq.pop()
    max_dq.append(right)

    # 维护单调递增队列（最小值）
    while min_dq and a[min_dq[-1]] >= a[right]:
        min_dq.pop()
    min_dq.append(right)

    # 收缩左边界，直到 max - min <= d
    while a[max_dq[0]] - a[min_dq[0]] > d:
        left += 1
        if max_dq[0] < left:
            max_dq.popleft()
        if min_dq[0] < left:
            min_dq.popleft()

    cur_len = right - left + 1
    if cur_len > best_len:
        best_len = cur_len
        best_l = left

print(f"{best_l + 1} {best_l + best_len}")
```

### 复杂度分析

**时间复杂度**：$O(n)$，每个元素最多进出队列各一次，均摊 $O(1)$

**空间复杂度**：$O(n)$，两个单调队列最坏情况各存 $n$ 个下标

## 小结

- 本题是经典的滑动窗口 + 单调队列模板题，核心在于将"任意两元素差值不超过 $d$"转化为"窗口 max - min ≤ d"
- 单调队列维护最值是 $O(n)$ 的利器，适用于所有"滑动窗口最值"场景
- 注意同等长度取最小起始位置，由于从左往右遍历，用严格大于（`>`）更新即可自然保证
